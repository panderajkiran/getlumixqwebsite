# Lumi6 Showcase Website

A premium, fully responsive static showcase website for Lumi6, built using vanilla HTML, modern CSS variables, and dynamic interactive elements.

## Features

- **Adaptive Capsule Navigation**: Dynamic scroll-linked capsule navbar that transforms smoothly into a compact floating layout.
- **Premium Typographic Rhythm**: Fine-tuned visual hierarchy featuring **Outfit** for brand moments, **Plus Jakarta Sans** for structure, and **Inter** for readable body content.
- **Floating Atmospheric Depth**: Slow, drifting vector cloud layer placed dynamically behind the Hero text stack.
- **Integrated Product Showcases**: Interactive, slowed-down autoplay product animation and video cards with subpixel edge-bleed protection.
- **Fully legibled FAQ Accordions**: Interactive accordion modules styled with brand terra-cotta highlight colors, adapting smoothly to light backgrounds.
- **Mobile Responsive Layout**: Breakpoint structures across all sections (Hero, Platform, FAQ) that adapt to stacked mobile and tablet viewport dimensions.

## Vercel Deployment

This project is deployed on Vercel as a static showcase. It utilizes a custom dummy build pipeline to fit Vite preset configuration.
